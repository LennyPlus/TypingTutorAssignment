# TypingTutor
A JavaFx application that helps users learn how to “touch type” for the Program Development in a Graphical Environment course at Vanier
By Anas issa

## Usage

1. Open the project in NetBeans
2. Download the required dependencies using Maven
3. Run the main application file: `App.java` (located in the `com.mycompany.typingtutor` package)
4. Type normally on your keyboard to try and match the displayed prompt text
